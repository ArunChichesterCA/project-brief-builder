# Project Brief Builder

A small web app that turns a rough project idea into a clear, structured project brief.

**Your job:** improve this app, one task at a time, the way a real development team works.

## How this project works

1. All your tasks are in the **Issues** tab. Do them **in order**, starting with Task 1.
2. Each task tells you exactly what to do and what "done" looks like.
3. Every change goes on a **branch**, then into a **pull request**. Only merge when the **Tests** check has a green tick.
4. When a task is done, it closes. Brett can see your progress here, so you don't need to message him after every step.

## Rules

- Do every task in **your own copy** of this project.
- Use made-up information only. Never type client details, case information or passwords into the app or into AI tools.
- If you're stuck for 20 minutes: search the exact error, or ask ChatGPT. Still stuck? Comment on the issue with what you tried and a screenshot, and message Brett.

## Useful commands

Run the app:

```bash
streamlit run app.py
```

Run the tests:

```bash
python -m unittest discover -s tests -v
```
